# Tindak lanjut audit antislop 003, 15 September 2026

Keenam temuan dari `audit-003-2026-09-14.md` diperbaiki (disetujui: 09-14).

## 09. Nav admin muat di desktop 1280px, SELESAI

Di `src/lib/layout.ts`, `.nav-link` dirapatkan pada `@media (min-width:1024px)`
(padding 12px 8px, gap 5px, font 13px). Hasil ukur browser nyata: `navScroll`
125px menjadi 0 di 1280px, 9 item terlihat penuh tanpa geser. Aturan geser
mobile tidak berubah.

## 10. Header brand 1 baris di HP, SELESAI

Header menampilkan nama pendek ("Bagarry", kata terakhir `APP_NAME`) di bawah
480px dan nama lengkap di desktop, plus menyembunyikan label peran (`.who`) di
layar sempit. Terukur: `brandShort:block/brandFull:none` di 360px dan sebaliknya
di 1280px. Judul dokumen dan desktop tidak berubah.

## 11. Badge antrean di nav, SELESAI

`loadUser` di `src/middleware.ts` menghitung `COUNT(*) payments pending` sekali
per request (hanya untuk admin) ke `c.set('pendingCount')`, diteruskan lewat
`page()`/`errorPage()` di `src/routes/shared.ts` ke `renderPage`. Nav
"Menunggu Verifikasi" menampilkan `.nav-count` (pil teal, putih 5,47:1) hanya
bila antrean > 0. Data audit: antrean sedang 0 sehingga badge tersembunyi,
tetapi plumbing terverifikasi di HTML (class `nav-count` ter-render di template).

## 12. Input 16px anti auto-zoom iOS, SELESAI

`.input` di `src/lib/layout.ts` naik dari 14px ke 16px. Tinggi 44px dan
`width:100%` tidak berubah, jadi tidak ada pergeseran layout. Label/hint tetap
12-13px karena bukan kolom ketik.

## 13. Dokumentasi kontrol sentuh, SELESAI

README bagian Arah desain mendapat butir "Ukuran kontrol sentuh": tombol tabel
38px di desktop vs 44px di mobile, dan font input 16px anti auto-zoom Safari.

## 14. Tabel audit terbaca di HP, SELESAI

- Kolom Aksi memakai label Indonesia (`Masuk`, `Verifikasi pembayaran`, ...).
- Kolom Perubahan memakai ringkasan satu baris (`changeSummary` di
  `src/lib/audit.ts`), bukan JSON mentah. Verifikasi: `{&quot;` 0 di halaman,
  contoh "Ditolak: Nominal transfer tidak sesuai."
- Kolom IP disembunyikan di bawah 640px (`.audit-table` + media query);
  terukur `ipVisible:false` di 360px. IP tetap ada di desktop dan API.
- E2E tes 11 diperbarui ke label Indonesia dan lulus (`npx playwright test -g
  "11 audit log"`: 1 passed melawan server audit 8791).
